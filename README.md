# Vegan Health Dashboard

A personal, searchable vegan nutrition hub — nutrients, foods, health topics, life
stages, herbs, myths and a glossary, Indian foods first. General information only,
not medical advice.

This is a private, unlisted preview. The page itself is marked `noindex, nofollow`
and not linked from anywhere public.

Built from [the working repo](https://github.com/sandeshraju555/vegan-health-dashboard-work)
(private). `app/` is the static site; `knowledge/knowledge.json` is the compiled
content, generated from that repo's `drafts/`.
